Build your own agent

Say what your agents send one another, write how each one perceives and thinks, and put them in an episode.

Free Agent is a Rust crate. Add it, with the runtime and the few crates an agent is written with:

cargo add free-agent tokio --features tokio/full
cargo add async-trait anyhow serde --features serde/derive

Five pieces

  • Message

    What the agents in an episode say to one another: one type for the whole episode, usually an enum.

  • Behavior

    How an agent perceives. receive takes each message the moment it arrives.

  • Think

    How an agent thinks, in a loop of its own, one thing at a time: a model call, a plan, a deadline.

  • Context

    How an agent acts, from either loop: it sends messages, stops other agents, and logs.

  • Episode

    Brings agents into being together, decides which can reach which, and runs them until they stop.

An agent

This one hears everything as it arrives and hands it to its thinking loop, which takes its time over each message and then answers.

use async_trait::async_trait;
use free_agent::{ActorId, Behavior, Context, Message, Think};
use serde::{Deserialize, Serialize};
use std::collections::HashSet;

/// What the agents in this episode say to one another.
#[derive(Debug, Clone, Serialize, Deserialize)]
enum Talk { Said(String) }
impl Message for Talk {}

/// Perceives: hears everything as it arrives, and hands it off.
struct Ears { context: Context<Talk> }

#[async_trait]
impl Behavior for Ears {
    type Message = Talk;
    type Log = Talk;
    fn context(&self) -> &Context<Talk> { &self.context }
    async fn receive(&mut self, heard: &Talk) -> anyhow::Result<()> {
        self.context.log(heard.clone());
        self.context.think(heard.clone())
    }
}

/// Thinks: takes its time over each message, then answers.
struct Mind { context: Context<Talk>, peers: HashSet<ActorId> }

#[async_trait]
impl Think for Mind {
    type Message = Talk;
    async fn think(&mut self, heard: &Talk) -> anyhow::Result<()> {
        let Talk::Said(words) = heard;
        let reply = ask_your_model(words).await;  // the Ears keep listening
        self.context.send(Talk::Said(reply), self.peers.clone())
    }
}

ask_your_model is yours: a call to a language model, a rule, a policy you’re training.

An episode

Each agent is described by an ActorInit: how it perceives, how it thinks, and whom it may reach. The episode wires them together, starts them all at once, and runs them until they stop, while the log is written as JSON Lines.

use free_agent::{ActorInit, Episode, console_log};
use std::collections::HashMap;
use std::time::Duration;
use tokio::sync::mpsc::unbounded_channel;

fn agent(peers: HashSet<ActorId>) -> ActorInit<Ears> {
    let reach = peers.clone();
    ActorInit {
        behavior: Box::new(|context| Ears { context }),
        think: Some(Box::new(move |context| Box::new(Mind { context, peers }))),
        can_send_to: reach,
        can_shut_down: HashSet::new(),
        has_logger: true,
    }
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let ann = agent(HashSet::from(["bob".to_string()]));
    let bob = agent(HashSet::from(["ann".to_string()]));
    let (logger, log) = unbounded_channel();
    let episode = Episode::new(
        HashMap::from([("ann".to_string(), ann), ("bob".to_string(), bob)]),
        logger,
    );
    let logging = tokio::spawn(console_log(log));
    episode.run(Duration::from_secs(60)).await?;
    logging.await??;
    Ok(())
}

Give one agent an opening move in start and the conversation begins. An app is this, grown up: an environment agent that keeps the rules, agents that play, and a log of everything they said.
