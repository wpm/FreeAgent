Social Deduction

Werewolf and Avalon, played by language models.

Social deduction games put agents in psychologically complicated situations. Some of the players are secretly on the other side, and everyone has to decide whom to trust from what the others say and how they vote.

The hidden players have to lie convincingly, keep their story straight, and work together without being seen to. The rest have to read intentions they can’t check, while everyone else is talking too and the clock is running. An accusation lands, a vote shifts, a quiet player suddenly speaks up. Every game ends with a winner, so each one is a measured result.

The games

  • Werewolf

    A village hides its werewolves. Each night the wolves kill, the seer learns one player’s nature and the doctor saves one life. Each day the village argues and votes someone out.

Set the table

  • Every player plays a strategy: a prompt and a model, or a random player that needs neither.
  • Mix them at one table: random werewolves against prompted villagers, or two prompts head to head.
  • Use any OpenAI-compatible server, hosted or on your own machine. The app finds LM Studio, Ollama, llama.cpp and vLLM by itself.
  • Every model is checked before it plays, so you know which ones can follow the rules.

Generate data from the command line

Social Deduction installs a command line beside its desktop app. social-deduction plays games headless, with models from any OpenAI-compatible server, local or hosted, and logs every event as JSON Lines.

# Write out the example tables, then play 500 games of Werewolf
social-deduction configs --write .
social-deduction play werewolf/prompted.toml --episodes 500 2> werewolf.jsonl
  • The game is told on standard output as it happens and logged on standard error, one JSON object per event.
  • --episodes N plays N games in a row and deals the roles afresh each time, so a seat says nothing about a side.
  • Each episode opens with a header naming the log format and the version that wrote it, and closes with how it ended.
  • API keys are redacted, so a log is safe to share.
  • Players, prompts and models are a TOML file. Open any log in the desktop app to step through the game message by message.

Download

Each installer gives you the desktop app, to watch games live and review them move by move, and the social-deduction command line, to play them by the hundred.

Download

Drag it to Applications, then choose Social Deduction ▸ Install Command-Line Tool…

Windows may warn that the app is from an unknown publisher: choose More info, then Run anyway.

The command line is installed to /usr/bin.
