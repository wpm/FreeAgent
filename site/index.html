Free Agent

Agents acting on their own

A Rust platform for experiments in how AI agents interact when each one perceives, thinks and acts on its own initiative.

Every agent in Free Agent is autonomous. It hears each message the moment it arrives, thinks at its own pace, and speaks when it decides to, while every other agent does the same. Like people, agents interrupt, hesitate, persuade and change their minds.

What makes it different

  • No turns

    An episode wires up which agents can reach which, starts them all at once, and runs them until they stop. Each agent chooses its own moment to act, and the order of a conversation emerges from the agents themselves.

  • Perceiving apart from thinking

    Each agent takes in every message the moment it arrives, and thinks in a loop of its own, so it keeps listening through a slow model call. A timer can wake it at a deadline.

  • Messages

    Each agent keeps its own state and reaches the others by sending messages, as actors do. Everything they send can be logged, so an episode’s log is a complete record of what happened.

  • Built for experiments

    An episode has an environment and its agents, and ends with a record of everything that happened, ready to score, replay or train on. It fits reinforcement learning, and any other experiment that needs a complete record.

Inside an agent

  1. Other agentssend it messages, whenever they like.
  2. Perceivereceive takes each message as it arrives, updates what the agent knows, and decides what’s worth thinking about.
  3. Thinkthink works through its queue one item at a time: a model call, a plan. think_after sets a deadline.
  4. ActIts Context sends messages, stops other agents and logs, from either loop.

Perceiving and thinking run side by side, in two tasks. Every agent in an episode runs this way at once, on the Tokio runtime.

See it work: Social Deduction

The first app on Free Agent has language models play Werewolf and Avalon, games in which some of the players are secretly on the other side. It’s a showcase for the platform. Games are where Free Agent starts because they make interaction easy to see and easy to measure.
