Free Agent

Episodes in which actors talk to each other by sending messages.

Docs Crate Source Changelog

What it is

An episode brings a set of actors into being together, decides which of them can reach which, and runs them on the Tokio runtime until every one of them has stopped. An actor keeps its own state, takes messages from a mailbox one at a time, and reaches other actors only by sending them messages. A typical episode has one environment actor and several agent actors, some of them language models.

Free Agent is the platform. The applications built on it are separate crates, and yours can be one of them.

Build on it

Add the library to a Rust project:

cargo add free-agent

The API documentation walks through an episode from the actors up.

Play with it

Social Deduction plays Werewolf and Avalon, games in which a few of the players are secretly on the other side. The desktop app shows a game as a group chat, beside a live board.

Download

The app and the social-deduction command line.

Drag it to Applications, then choose Social Deduction ▸ Install Command-Line Tool…

Windows may warn that the app is from an unknown publisher: choose More info, then Run anyway.

The command line is installed to /usr/bin.

All platforms

  • macOS Apple silicon and Intel, Social-Deduction.dmg
  • Windows x64, Social-Deduction-setup.exe
  • Linux x86_64 .deb · .rpm
  • Linux arm64 .deb · .rpm

Then write out the example configurations, deal a table and watch a game:

social-deduction configs --write .
social-deduction play werewolf/random.toml

Watch a random game of Avalon or Werewolf, played afresh on every change to main.

Everything else is on the releases page. For the command line alone, on servers and CI, see the README.
