Twenty Questions

A secret object, a table of language models, and twenty guesses among them.

A host thinks of something. The players have twenty yes-or-no guesses among them to name it, so before each one they have to agree on what is worth asking.

Everyone talks at once, with no turns. The players think aloud, build on one another’s ideas, and settle on a guess, and only a guess counts: a formal question put to the host, which answers each in the order it came. The players win when a guess names the object. The host wins when the guesses or the time run out.

The host and the players

  • The host runs the game. It picks the secret object, or takes the one you name, then numbers and answers each guess and ends the game.
  • The host picks with a prompt of its own, at a high temperature, from a category drawn at random, so one game’s object is rarely the last one’s.
  • One to twelve players, Alice to Leo, each a prompt and a model. Mix them at one table: a cautious prompt beside a bold one, or a small model beside a large one.
  • Every game has a winner, so every game is a result.
  • Use any OpenAI-compatible server, hosted or on your own machine. The app finds LM Studio, Ollama, llama.cpp and vLLM by itself.
  • Every model is checked before it plays, so you know which ones can follow the rules.

A sample in your browser

Watch a game right in your browser: a game played by language models, from the first question to the guess that names the object. Your own tables and models, and the command line, are in the app.

Generate data from the command line

Twenty Questions installs a command line beside its desktop app. twenty-questions plays games headless, with models from any OpenAI-compatible server, local or hosted, and logs every event as JSON Lines.

# Write out the example table, then play 500 games
twenty-questions configs --write .
twenty-questions play prompted.toml --episodes 500 2> games.jsonl
  • The game is told on standard output as it happens and logged on standard error, one JSON object per event.
  • --episodes N plays N games in a row, dealing the strategies to the seats afresh and picking a new object each time.
  • Each episode opens with a header naming the log format and the version that wrote it, and closes with how it ended.
  • API keys are redacted, so a log is safe to share.
  • Players, prompts and models are a TOML file. Open any log in the desktop app to step through the game message by message.

Download

Each installer gives you the desktop app, to watch games live and review them move by move, and the twenty-questions command line, to play them by the hundred.

Download

Drag it to Applications, then choose Twenty Questions ▸ Install Command-Line Tool…

Windows may warn that the app is from an unknown publisher: choose More info, then Run anyway.

The command line is installed to /usr/bin.
